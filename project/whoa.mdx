At the heart of 9social-user-leo sits a file called `Whoa`. It is the project's primary artifact — the thing the project ships. While most repositories are judged by the complexity of their code, this one is defined by the deliberate simplicity of a single file containing a single word. Understanding `Whoa` is understanding the project.

## Contents

The complete contents of the `Whoa` file are as follows:

```text
wow
```

That is the entirety of the file. One word, no trailing metadata, no configuration — just the output itself.

## Purpose

The `Whoa` file is the lion's squeak. The project's tagline — *the lion that squeaked* — sets up an expectation of something loud and powerful, and then subverts it with something small and surprising. The word `wow` is that subversion: a moment of quiet wonder rather than a commanding roar.

This is the project's deliberate, minimal artifact. It exists to prove that a project can be complete without being large, and meaningful without being complex. The `Whoa` file does not do more than it needs to — and that restraint is entirely intentional.

<Note>
  The Whoa file is intentionally minimal. Its simplicity is a feature, not an oversight.
</Note>

## Reading the File

You can read the `Whoa` file at any time from the command line using `cat`:

```bash
cat Whoa
```

Expected output:

```text
wow
```

No special tooling, runtimes, or interpreters are required. The file is plain text and can be opened in any editor or read in any terminal.
