Welcome to **9social-user-leo**. This guide walks you through cloning the repository and reading the project's single artifact — the `Whoa` file — in just a few steps. Because the project has zero dependencies and no build process, getting up and running takes less than two minutes regardless of your environment.

<Steps>
  <Step title="Prerequisites">
    Before you begin, make sure you have the following ready:

    - **Git** installed on your machine. Verify by running:
      ```bash
      git --version
      ```
    - A **terminal** (macOS Terminal, Linux shell, Windows Terminal, Git Bash, or equivalent).

    That's it — no package managers, runtimes, or additional tools are required.
  </Step>

  <Step title="Clone the Repository">
    Clone **9social-user-leo** from GitHub to your local machine:

    ```bash
    git clone https://github.com/Sn00per625/9social-user-leo.git
    ```

    This creates a new directory called `9social-user-leo` in your current working folder containing all project files.
  </Step>

  <Step title="Navigate Into the Directory">
    Move into the newly cloned project directory:

    ```bash
    cd 9social-user-leo
    ```

    You can list the contents to confirm everything is in place:

    ```bash
    ls
    ```

    You should see two files: `README.md` and `Whoa`.
  </Step>

  <Step title="Read the Whoa File">
    Open the project's single artifact:

    ```bash
    cat Whoa
    ```

    You'll see the following output:

    ```text
    wow
    ```

    Congratulations — you've just experienced the full, intentional output of **9social-user-leo**.
  </Step>
</Steps>

## What Just Happened?

The `Whoa` file is the project's **single artifact** — and that's entirely by design. Rather than generating a cascade of build outputs, configuration files, or compiled assets, **9social-user-leo** produces exactly one thing: the word `wow`.

This isn't a placeholder waiting to be replaced. It's a deliberate, minimal output that reflects the project's core philosophy — that the most honest version of any project is its simplest possible expression. Before you add complexity, you have to start somewhere. This is that somewhere.

The lion has squeaked. What you build next is up to you.
