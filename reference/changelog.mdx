## Versioning Policy

**9social-user-leo** follows [Semantic Versioning](https://semver.org) (SemVer), using the `MAJOR.MINOR.PATCH` format:

- **PATCH** — backwards-compatible bug fixes and minor corrections (e.g. `0.1.1`)
- **MINOR** — new, backwards-compatible features or additions (e.g. `0.2.0`)
- **MAJOR** — breaking changes that are not backwards-compatible (e.g. `1.0.0`)

This ensures that version numbers are meaningful and that users can upgrade with confidence, knowing exactly what kind of change to expect.
